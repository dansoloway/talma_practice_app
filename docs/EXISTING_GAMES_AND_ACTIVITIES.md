# Existing Games and Activities

This document describes all the English practice games and activities currently available in TALMA Practice Pal.

---

## Overview

The system currently has **4 main types of activities** that students can practice:

1. **Vocabulary Presentation** (Passive learning)
2. **Sentence Completion (Prompts)** (Active practice)
3. **Matching Games** (Active practice)
4. **Flashcard Games** (Active practice)

All activities are organized within **Lessons**, which can be grouped by grade level and session number.

---

## 1. Vocabulary Presentation

**Type:** Passive learning / Reference material  
**Location:** Shown at the top of each lesson page  
**Purpose:** Introduce vocabulary words before practice activities

### Features:
- **Display Format:**
  - Grid layout showing vocabulary words
  - Each word shows:
    - English word (required)
    - Image (optional, auto-generated or uploaded)
    - Audio button to hear pronunciation (auto-generated TTS)
    - Hebrew translation (optional, toggleable)
    - Arabic translation (optional, toggleable)

- **Student Interaction:**
  - Click audio button to hear word pronunciation
  - Toggle Hebrew/Arabic translations on/off
  - No scoring or completion tracking
  - Purely informational/reference

### Technical Details:
- Uses lesson's vocabulary items
- Images can be auto-generated or manually uploaded
- Audio is auto-generated using TTS (text-to-speech)
- Supports multiple languages (English, Hebrew, Arabic)

## 2. Sentence Completion (Prompts)

**Type:** Active practice game  
**Icon:** 📝  
**Purpose:** Practice completing sentences with correct vocabulary words

### How It Works:
1. Student sees a sentence template with a blank (e.g., "My favorite color is ___")
2. Student sees multiple choice options (words or images)
3. Student selects/drags the correct word to fill the blank
4. System shows feedback (correct/incorrect)
5. Student hears the complete sentence with correct pronunciation
6. Student can record themselves repeating the sentence (optional)
7. Progresses through all prompts in the lesson

### Features:
- **Question Format:**
  - Prompt text (question/instruction)
  - Sentence template with placeholder (e.g., `"I like to {}"`)
  - Multiple choice options (2+ options per prompt)
  - Options can be:
    - Text labels
    - Images
    - Both (image + text label)

- **Audio Features:**
  - Prompt audio (optional) - plays the question
  - Word audio (optional) - plays individual option words
  - Sentence audio (auto-generated) - plays complete sentence with selected word
  - Student recording (optional) - allows students to record themselves

- **Feedback:**
  - Visual feedback (green for correct, red for incorrect)
  - Shows correct answer if student gets it wrong
  - Score tracking (correct/total)
  - Completion percentage

- **Navigation:**
  - Previous/Next buttons
  - Finish button on last question
  - Can restart after completion

### Technical Details:
- Each prompt has a `correct_answer` field (1-based index)
- Options can have images, text, and audio
- Sentence audio is auto-generated by combining template + selected option
- Tracks activity events (started/completed) for analytics
- Drag-and-drop interface (also supports click-to-select for mobile)

## 3. Matching Games

**Type:** Active practice game  
**Icon:** 🔗  
**Purpose:** Match vocabulary pairs (memory/concentration game)

### How It Works:
1. Student sees a grid of face-down cards
2. Student clicks two cards to flip them
3. If cards match (same vocabulary item), they stay face-up
4. If cards don't match, they flip back
5. Goal: Match all pairs in the grid
6. Timer tracks completion time

### Features:
- **Grid Sizes:**
  - 4x4 grid (8 pairs)
  - 6x6 grid (18 pairs)
  - 8x8 grid (32 pairs)

- **Card Types:**
  - Each vocabulary item appears twice in the grid
  - Cards can show:
    - Image only
    - Word only
    - Audio only (with play button)
    - Combination of above

- **Game Modes:**
  - Image ↔ Image (match images)
  - Image ↔ Word (match image to word)
  - Word ↔ Word (match words)
  - Audio ↔ Word (match audio to word)
  - Audio ↔ Image (match audio to image)

- **Features:**
  - Timer (shows completion time)
  - Match counter (shows pairs matched)
  - Visual feedback (blue highlight when selected, green when matched)
  - Completion screen with time and score
  - Can restart game

### Technical Details:
- Uses vocabulary from the lesson
- Requires enough vocabulary items for grid size (e.g., 8 items for 4x4 grid)
- Cards are shuffled randomly each game
- Tracks activity events (started/completed) with duration for analytics

## 4. Flashcard Games

**Type:** Active practice game  
**Icon:** 🎴  
**Purpose:** Practice vocabulary recognition through flashcards

### How It Works:
1. Student sees a flashcard (one side of vocabulary)
2. Student sees multiple choice options
3. Student selects the correct match
4. System shows feedback
5. Moves to next card
6. Completes all cards in the set

### Features:
- **Game Types:**
  - **Image → Word:** Show image, choose correct English word
  - **Audio → Word:** Play audio, choose correct English word (supports Hebrew/Arabic options)

- **Card Configuration:**
  - Number of cards per game (1-50, default: 10)
  - Cards randomly selected from lesson vocabulary
  - Each card shows one side, student chooses matching option

- **Language Support:**
  - Audio → Word mode supports:
    - English audio → English word
    - English audio → Hebrew word
    - English audio → Arabic word
  - Mode can be changed during game

- **Features:**
  - Progress indicator (card X of Y)
  - Score tracking (correct/total)
  - Visual feedback (correct/incorrect)
  - Completion screen with score and accuracy percentage
  - Can restart game

### Technical Details:
- Uses vocabulary from the lesson
- Cards are shuffled randomly each game
- Supports multiple game types in one game (student can switch)
- Tracks activity events (started/completed) with score and duration for analytics

## Common Features Across All Activities

### Audio Support:
- All activities support audio playback
- Audio is auto-generated using TTS (text-to-speech)
- Supports multiple voices/languages
- Audio files are pre-generated and stored

### Image Support:
- Images can be auto-generated or manually uploaded
- Images are stored in storage and served via CDN/public storage
- Supports various image formats

### Analytics Tracking:
- All activities track:
  - Session start/completion
  - Duration
  - Score/performance (where applicable)
  - Device type (mobile/desktop)
  - Location (country/city)

### Mobile Support:
- All activities are mobile-responsive
- Touch-friendly interfaces
- Drag-and-drop works on mobile (with fallback to tap)

### Activity Ordering:
- Activities can be reordered within lessons
- Order determines sequence students see activities
- Vocabulary presentation always appears first (if vocabulary exists)

## Current Limitations / Gaps

### What's Missing:
1. **No speaking practice games** - Only recording (not evaluated)
2. **No listening comprehension** - No audio-only comprehension exercises
3. **No writing practice** - No typing/spelling exercises
4. **No grammar-specific games** - No games focused on grammar rules
5. **No reading comprehension** - No passages with questions
6. **No pronunciation feedback** - Recording exists but no evaluation
7. **No adaptive difficulty** - All activities are fixed difficulty
8. **No multiplayer/competitive** - All activities are single-player
9. **No story/narrative activities** - No connected story-based practice
10. **No fill-in-the-blank variations** - Only one type of sentence completion

### What Could Be Enhanced:
- More game types for existing activities
- More interaction types (typing, speaking, etc.)
- More feedback mechanisms
- More gamification elements (badges, streaks, etc.)

## Technical Architecture

### Data Models:
- **Lesson** - Container for all activities
- **Vocabulary** - Words with translations, images, audio
- **Prompt** - Sentence completion questions
- **Option** - Answer choices for prompts
- **MatchingGame** - Matching game configuration
- **FlashcardGame** - Flashcard game configuration
- **Response** - Student answers to prompts
- **ActivityEvent** - Analytics tracking for all activities

### Activity Flow:
1. Student visits lesson page
2. Sees vocabulary presentation (if available)
3. Sees list of activities
4. Selects activity to practice
5. Completes activity
6. Returns to lesson page or moves to next activity
