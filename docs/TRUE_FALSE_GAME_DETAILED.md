# True/False Game - Detailed Explanation

## 🎯 Game Overview

The **True/False Game** is a simple, engaging activity where students listen to statements about science content and determine if they're correct or incorrect. 

**Language Level:** CEFR A1 (Beginner) - Very simple English with basic vocabulary and short sentences.

Perfect for testing comprehension, reinforcing facts, and building critical thinking skills while practicing English listening.

---

## 🎮 How It Works

### Basic Flow:
1. **Audio plays statement** (e.g., "Ice is cold") 🔊
2. **Student can click to show text** (optional)
3. **Student selects True or False**
4. **Immediate feedback** with simple explanation
5. **Progresses to next statement**

### Visual Design:
```
┌─────────────────────────────────────┐
│  Question 3 of 10                   │
│                                      │
│  🔊 [Play Audio Button]             │
│                                      │
│  [Show Text] (optional button)      │
│                                      │
│  ┌──────────┐    ┌──────────┐      │
│  │   TRUE   │    │  FALSE   │      │
│  └──────────┘    └──────────┘      │
└─────────────────────────────────────┘

After selection:
┌─────────────────────────────────────┐
│  ✅ Correct!                         │
│                                      │
│  "Yes! Ice is cold."                 │
│                                      │
│  [Next Question]                     │
└─────────────────────────────────────┘
```

### Language Level: CEFR A1
- **Simple words** - Only basic vocabulary
- **Short sentences** - 5-10 words maximum
- **Simple grammar** - Present tense (is, are, do, have)
- **No complex structures** - No passive voice, conditionals, or idioms

## 🎨 Game Variations

### Variation 1: Image-Based
- Show image only
- Statement appears below image
- Student determines if statement matches image

**Example:**
```
[Image: Scientist observing through microscope]
Statement: "The scientist is observing something."
→ TRUE ✅
```

---

### Variation 2: Audio + Image
- Play audio statement
- Show image
- Student determines if audio matches image

**Example:**
```
Audio: "Ice melts faster in warm water" 🔊
[Image: Ice in warm water]
→ TRUE ✅
```

---

### Variation 3: Definition Matching
- Show vocabulary word
- Show definition statement
- Student determines if definition is correct

**Example:**
```
Word: "hypothesis"
Statement: "An educated guess about what will happen"
→ TRUE ✅
```

---

### Variation 4: Procedure Steps
- Show step statement
- Show image of procedure
- Student determines if step is correct for that procedure

**Example:**
```
Statement: "First, fold the paper in half"
[Image: Paper airplane instructions showing fold step]
→ TRUE ✅
```

## 📊 Question Types

### 1. **Fact-Based Questions**
- Clear right/wrong answers
- Science facts and definitions
- **Example:** "A hypothesis is an educated guess" → TRUE

### 2. **Process Questions**
- About procedures and steps
- May depend on specific procedure
- **Example:** "You add vinegar before baking soda" → Depends

### 3. **Vocabulary Questions**
- Test understanding of word meanings
- Use vocabulary in context
- **Example:** "To observe means to watch carefully" → TRUE

### 4. **Common Misconception Questions**
- Address typical student errors
- Reinforce correct understanding
- **Example:** "Ice melts faster in cold water" → FALSE

### 5. **Comprehension Questions**
- Test if student understood the lesson
- Require deeper thinking
- **Example:** "After mixing vinegar and baking soda, nothing happens" → FALSE

## 💻 Technical Implementation

### Data Structure:
```php
TrueFalseQuestion {
    id
    lesson_id
    statement: "Vinegar and baking soda make a reaction"
    is_true: true/false
    explanation: "Yes! When you mix them, they react..."
    image_path: optional
    audio_path: optional
    category: "science_facts" | "procedures" | "vocabulary"
    difficulty: "easy" | "medium" | "hard"
}
```

### Game Flow:
1. Load questions for lesson
2. Shuffle questions
3. Show statement + context
4. Wait for True/False selection
5. Show feedback (correct/incorrect + explanation)
6. Move to next question
7. Show completion screen with score

### Scoring:
- **Correct Answer:** +1 point
- **Incorrect Answer:** 0 points
- **Show:** Score (X/Y) and percentage

## 📈 Content Generation Strategy

### From Existing Content:

#### Option 1: Convert Prompts to Statements
**Prompt:** "Complete the sentence: We used many {} for this experiment."
**Options:** materials, tools, colors

**True/False Questions:**
- "We used many materials for this experiment" → TRUE
- "We used many colors for this experiment" → FALSE

#### Option 2: Use Vocabulary Definitions
**Vocabulary:** "hypothesis"
**True/False:**
- "A hypothesis is an educated guess" → TRUE
- "A hypothesis is the final answer" → FALSE

#### Option 3: Create from Lesson Content
**Lesson:** "Making a Volcano"
**True/False:**
- "You need vinegar and baking soda to make a volcano" → TRUE
- "You can make a volcano with just water" → FALSE

## 🎯 Recommended Question Distribution

For a typical lesson with 10 True/False questions:

- **5 Fact-Based** (50%) - Clear science facts
- **2 Process-Based** (20%) - Procedures and steps
- **2 Vocabulary** (20%) - Word meanings
