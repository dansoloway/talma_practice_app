## 🚀 Usage

### Generate Questions with AI

```bash
# Generate 6 questions for a lesson
php artisan true-false:generate {lesson_id}

# Generate 8 questions with auto-approval and audio
php artisan true-false:generate {lesson_id} --count=8 --approve --generate-audio
```

### Access Admin Interface

1. Go to any lesson management page: `/admin/lessons/{lesson}/manage`
2. Click **"True/False"** button in Activities section
3. Or go directly: `/admin/lessons/{lesson}/true-false-questions`

## 📋 Admin Interface Features

### Index Page (`/admin/lessons/{lesson}/true-false-questions`)

**Shows:**
- Stats: Total questions, Approved & Active, Pending Approval
- Pending questions section (with bulk approve)
- Approved questions section
- Generate questions reminder

**Actions:**
- ✅ Approve individual questions
- ✅ Bulk approve (select multiple, approve all)
- ✅ Edit questions
- ✅ Delete questions
- ✅ Create new question manually

### Create Page (`/admin/lessons/{lesson}/true-false-questions/create`)

**Fields:**
- Statement (required) - The True/False statement
- Correct Answer (required) - True or False
- Explanation (required) - Shown to students after answer
- Category (optional) - science_facts, procedures, vocabulary, etc.
- Approved checkbox - Auto-approve on creation
- Active checkbox - Make question active
- Sort Order - Display order

### Edit Page (`/admin/lessons/{lesson}/true-false-questions/{id}/edit`)

**Same fields as Create, plus:**
- Audio preview (if audio exists)
- Delete button

### Show Page (`/admin/lessons/{lesson}/true-false-questions/{id}`)

**Displays:**
- Full question details
- Audio player (if audio exists)
- Status badges
- Created/updated timestamps
- Quick actions (Edit, Approve, Delete)

## 🎯 Workflow

### Step 1: Generate Questions
```bash
php artisan true-false:generate 1 --count=6
```

### Step 2: Review in Admin
1. Go to `/admin/lessons/1/true-false-questions`
2. See pending questions
3. Review each question

### Step 3: Approve Questions
- **Individual:** Click "Approve" button
- **Bulk:** Select multiple checkboxes, click "Approve Selected"
- **Or:** Edit first, then approve

### Step 4: Edit if Needed
- Click "Edit" on any question
- Modify statement, answer, or explanation
- Save changes

### Step 5: Create Manual Questions
- Click "+ Create Question"
- Fill in form
- Save (auto-approved if checkbox checked)

## 🔧 Routes

All routes are under `/admin/lessons/{lesson}/true-false-questions`:

- `GET /` - List all questions (index)
- `GET /create` - Create form
- `POST /` - Store new question
- `GET /{id}` - Show question details
- `GET /{id}/edit` - Edit form
- `PUT /{id}` - Update question
- `DELETE /{id}` - Delete question
- `POST /{id}/approve` - Approve question
- `POST /{id}/reject` - Reject question
- `POST /bulk-approve` - Approve multiple questions

## 📊 Question Status

### Pending Approval
- Questions generated by AI (default)
- Questions created manually with "Approved" unchecked
- Shown in "Pending Approval" section
- Cannot be played by students

### Approved & Active
- Questions approved by admin
- `is_active = true`
- Shown in "Approved Questions" section
- Can be played by students

### Inactive
- Approved but `is_active = false`
- Hidden from students
- Can be reactivated

## 🐛 Troubleshooting

### Questions not showing
- Check `is_approved = true` for approved section
- Check `is_active = true` for active questions
- Verify lesson_id matches

### Bulk approve not working
- Make sure questions are selected (checkboxes checked)
- Check browser console for JavaScript errors
- Verify CSRF token is present

### Audio not playing
- Check `audio_path` is set
- Verify file exists at path
- Check file permissions
