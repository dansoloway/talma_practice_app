# ChatGPT Prompt: CVC Word Vocabulary Progression for 6-Year-Old English Learner

Use this prompt with ChatGPT to get a structured vocabulary progression plan:

---

**I'm teaching my 6-year-old daughter English as a second language. I want to use CVC (consonant-vowel-consonant) words, starting with just a few letters and building up systematically.**

**Please provide:**

1. **Starting Point**: Recommend 3-5 letters to begin with (mix of consonants and vowels). Explain why these are good starting letters.

2. **Progressive Word Lists**: Create 5-7 progressive levels, each building on the previous:
   - Level 1: Words using only the starting letters (e.g., if starting with a, t, p, s, m → words like: at, pat, sat, mat)
   - Level 2: Add 2-3 new letters, show new words possible
   - Level 3: Add 2-3 more letters, show new words
   - Continue until Level 5-7 with a good foundation

3. **For Each Level, Provide:**
   - The letters available at that level
   - 8-12 CVC words that can be formed (prioritize common, concrete nouns and simple verbs)
   - 2-3 simple sentences using those words (for context)
   - Why these words are good choices (concrete, visual, age-appropriate)

4. **Selection Criteria**: Prioritize words that are:
   - Concrete and visual (cat, dog, hat, pen - things she can see/touch)
   - Common in children's vocabulary
   - Easy to illustrate or demonstrate
   - Useful for building simple sentences
   - Age-appropriate for a 6-year-old

5. **Progression Strategy**: Explain the learning path:
   - How many words per level?
   - When to introduce new letters?
   - How to ensure mastery before moving on?
   - What patterns to emphasize (word families like -at, -an, -en)?

6. **Final Recommendation**: Suggest the optimal starting set of 8-12 words for Level 1, with the specific letters to begin with.

**Please format this as a clear, actionable plan I can use to create vocabulary lessons.**

---

## Alternative Shorter Version:

**I'm teaching my 6-year-old daughter English using CVC words. I want to start with just 3-5 letters and build up systematically. Please:**

1. Recommend the best 3-5 starting letters (mix of consonants and vowels) and why
2. Create 5 progressive levels, each adding 2-3 new letters
3. For each level, list 8-12 CVC words that can be formed (prioritize concrete, visual, common words)
4. Include 2-3 simple example sentences per level
5. Explain the progression strategy and when to move to the next level

**Format as a clear lesson plan I can follow.**
